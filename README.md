A single hub-and-spoke n8n workflow that turns a plain-English message like *"add my dentist appointment for tomorrow 5pm"* into a real action — no hardcoded intents, the agent reasons about which of its 19 tools to call, executes it against live Google APIs, and replies like a person would. Ships with a Streamlit chat dashboard as the front door and a rolling memory buffer so follow-up messages ("update **that** note") resolve correctly without repeating context.

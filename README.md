**ELC Summer Intern — Privacy-Preserving Federated Learning for Medical Diagnosis**
*Experiential Learning Centre, Thapar Institute of Engineering & Technology · Jun 2026 – Present*

- Built an end-to-end federated learning pipeline across 3 multi-country medical imaging datasets (ultrasound & mammography, 3,900+ images) with patient-aware data splitting — benchmarked 11 CNN/classical backbones, beating a published FL baseline's per-client AUC by up to **0.34**
